# 商用模型提示词审计与策略 v1

版本：`commercial-2026-09-v1`，2026-09-19。

## 审计范围与变更

| 调用链 | 处理 |
|---|---|
| 文档智能导入 | 保留原文行号与集名空值规则；明确不因小标题、场景转换而过度拆集，已有集边界优先 |
| 原著事件提取 | 按因果事件聚合，区分事实和推断；新商用任务使用较大分块，优先段落边界，保留上一段末尾供指代衔接 |
| 全剧/单集改编 | 保留来源 ID、已完成集保护；补充叙事目标与因果，付费策划仅在明确启用时参与 |
| 剧本/直接剧本 | 人物动机、对白潜台词、动作与反应占时；修正 120 秒任务仍被禁止写“分钟级短片”的矛盾 |
| Film Bible | 复用身份，区分持续状态与瞬时动作，机械结构等不变量明确入卡 |
| 分镜导演 | 视频描述不依赖已生成图片；一个叙事目的可包含连续动作节拍；参考编号留给真实编译器 |
| 资产参考图 | 分类构图规则；状态明确变化优先，未变化部分继承，遵守资产画幅 |
| 视频参考编译 | 分开身份、场景、道具用途，携带基础/状态链不变量；保留对白、动作参考与实际素材编号 |
| 音频 | 检查现有 Seed TTS context_texts 情绪接口；保留声线参考与完整对白两条路径，未虚构跨模型声音参数 |
| AI 助手 | 更新可选构图指南，修复主动建议仍把无分镜图当作必经步骤的问题 |
| 任务详情 | 新任务展示提示词策略版本；Schema 版本继续单独记录，不伪称媒体接口接收了独立 System 消息 |

## 模型与供应商边界

- 新版豆包事实提取/结构分析温度 0.2，创作 0.6。它们是应用默认值，不是宣称厂商最优值；需要真实案例对比继续校准。
- 未核实采样参数的其他云端文本模型不强制 temperature，采用端点默认；本地及旧任务保留原策略。
- 输出预算沿用既有应用上限，新商用普通文本任务不再落入通用 4096 默认。显式 max_tokens 保持优先；这些数字不代表模型上下文能力。
- 新豆包事件任务正文分块预算 16000 字符，其他云端 10000，本地/旧快照 6000；额外最多 800 字符前文仅用于指代，不重新提取事件。原文字符完整保留。
- 修复不再截取前 24000 字符：完整传入结果，商用完整结果预算 160000 字符，本地 24000，超过就明确失败且不额外调用。这是应用保护预算，不是模型 token 上限。输入特别大仍应分段处理。
- Seedance/Wan/H3 保留各供应商已经验证的参考协议与编号编译。没有把 H3 底层英文六段式格式直接塞进可能已有上游增强处理的托管端点，也没有新增自动翻译或提示词润色调用。

不更换 Schema 数据结构、不重写历史任务、不自动重新生成已有素材、不增加模型调用阶段。保留原有有限修复次数。
自动测试检验数据完整性、任务快照、旧策略兼容、抽取分块、参考清单和语义约束；没有进行付费新旧成片 A/B 测试，不能据此声称画质或剧情质量提升了特定幅度。

后续质量验收案例：无章节长原著是否过碎、120 秒多角色剧本是否可表演、前后集伤势与道具是否连续、无手臂机器人是否保持结构、变身状态是否正确继承、无构图图时视频描述是否完整。使用同一输入与相同模型配置比较，保存两份结果，不覆盖用户项目。
