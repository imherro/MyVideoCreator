# AI助手

左侧导航栏底部、设置上方为 AI助手。面板与项目库/任务中心互斥，点击外部区域或关闭按钮可收起；在同一页面会话中保留输入草稿，聊天记录持久化到服务器，按整部作品隔离。切换 EP 保留作品对话，但每条回答标记提问时的 EP 和页面。没有作品时也可咨询。

## 打开即诊断

`GET /api/assistant/context` 读取当前保存状态：剧本、分镜、视觉绑定、参考图锁定、生成结果与最近/活动任务。返回简洁的状态卡、下一步定位入口和三个相关问题。打开面板、切换集或页面时更新，不调用模型、不生成任务、不持续轮询。选中图像/视频节点时复用参考编译校验；也支持问题中明确指定 SHOT 02 或镜头 2。

## 聊天

`POST /api/assistant/chat` 使用作品默认文本模型；无作品时复用系统新作品默认文本服务选择。支持现有 OpenAI-compatible、火山方舟、幻场和 RunningHub 文本协议。内置本地模型需要已经启动且与所选模型一致，助手不会为了聊天自动装卸 GPU 模型。服务或模型不可用时明确报错，不自动切换。

响应为 NDJSON，包含 start（捕获上下文/定位按钮）、delta、done/error。聊天不进入 jobs，也不增加制作任务角标。每个作品同时一个回答，请求 ID 去重，超时/断线不自动重试。停止会关闭上游请求并保存已收到内容；服务重启将未完成记录标为 interrupted。浏览器普通局域网 HTTP 也支持请求 ID 生成。

`GET /api/assistant/history` 返回当前作品最近 80 条消息；模型上下文使用最近 12 条完成消息，每条带原 EP 标签。运行状态、报错、镜头提示词等作为只读数据提供，不作为系统指令；供应商 Key 不进入提示词，已知密钥及地址签名会脱敏。按需摘要，不默认发送整部原著或媒体文件。

当前版本说明维护在 `backend/assistant_guide.md`。导航动作由服务端白名单生成，只能打开现有工作区、节点、设置或任务详情。助手不会修改项目、锁定资产、提交生成、删除或恢复内容。新版使用流程改动时应同步更新此指南。

## 验证

- `tests/test_assistant.py`：作品隔离、当前集上下文、只读/零制作任务、幂等、并发、失败保留、停止、密钥脱敏、回收站访问、真实参考编译守卫、主动提示零模型调用、旧失败不覆盖新成功。
- `tests/assistant_chat.test.mjs`：UTF-8 分块、断流、错误正文仅读取一次、EP 标签、局域网 HTTP 请求 ID。
- 隔离数据目录中完成一次真实火山文本模型聊天，验证“EP02 无剧本 → 完善本集剧本”的回答与可用导航。打开状态卡本身不产生模型调用。
