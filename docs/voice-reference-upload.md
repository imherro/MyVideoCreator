# 角色声音样本：上传与豆包试听统一流程

在“塑角造景 → 角色 → 角色固定声音”选择声音来源：

- **豆包音色**：选服务、音色和试听文本，生成试听后锁定。
- **上传声音**：确认拥有使用权，上传 MP3/WAV，或选择本作品已有音频，保存为草稿；试听后锁定。无需豆包服务、Key、Speaker ID 或试听台词。授权记录是用户声明，不代表平台核验。

角色可以保留多个已锁定版本。“默认音色”选择当前生效版本；新草稿和新建声音版本不会自动替换旧默认。角色状态在“使用音色”中选择基础角色的锁定版本。共享声音仍存储在 Production 的 Film Bible 中，同作品各集复用。

## 两种对白方式

- 音色样本参考：只收集本镜说话角色的已锁定样本，台词与情绪来自结构化对白。不会调用 TTS，不用先生成整集对白；样本不决定镜头时长，不加入剪辑对白轨，也不覆盖视频声音。
- 完整对白参考：保留原有逐句 TTS 与时序编排。上传样本不等于 TTS 音色注册，本版本不能用其自动逐句合成；请选择音色样本参考。不会换成其他音色。

## 文件和版本

系统上传上限为 30 MB / 120 秒，支持真正可解码的 MP3/WAV 纯音频。建议清晰、单人、少背景噪声；内容不必是影片台词。提交模型时另检查当前适配器的格式、时长、总时长和数量限制，不自动裁剪、变速或混音。文件存储复用现有素材接口；幻场使用短期签名 URL，其他适配器沿用已实现的媒体协议。

上传只创建草稿，失败不改变锁定版本。锁定样本不可原地替换。旧豆包配置没有 source 字段时继续按豆包处理，历史任务和旧完整对白模式不改写。新任务快照包含声音来源、角色、版本、素材、时长与参考编号。修改生效声音只使相关视频待更新，保留旧视频。

## 实现入口

- `src/filmBible/voices.ts`：来源、配置身份、草稿、锁定及版本选择。
- `FilmBiblePanel.tsx` / `main.tsx`：上传/素材选择、声明、试听和保存。
- `backend/voice_reference_uploads.py`：文件解码、归属、声明和版本校验。
- `backend/voice_samples.py`：与已有视频单镜头/批量/预览共用声音参考编译。
- `backend/video_dialogue.py`：保留完整对白分支，拒绝上传样本冒充 TTS。

## 验收

1. 无豆包配置时，角色选择上传声音，勾选使用权并上传短 MP3/WAV；试听、锁定，刷新后仍可使用。
2. 新建同作品第二集，角色状态选择此版本，设镜头为多模态、音色样本参考，填写结构化对白。
3. 展开最终提交与参考清单，应显示上传声音、角色映射、版本及实际时长，图片与动作参考同时保留。
4. 换成完整对白参考，应提示能力不足；切回音色样本参考即可。
5. 新建声音草稿，旧默认继续生效；锁定后通过默认音色明确启用新版本。
6. 豆包试听运行时切换并上传声音，旧任务完成不能覆盖上传样本。

本次使用小型本地音频与 mock HTTP 验证，不以 mock 结果宣称真实音色效果已验收。沿用方舟、幻场 AI、RunningHub 已实现的 Seedance 多模态音频分支；具体模型/账号限制仍在提交时验证。锁定仅指参考样本及版本，不承诺生成音色完全一致。未接入新的 TTS/克隆/训练服务。
