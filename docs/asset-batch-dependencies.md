# 批量资产生成的依赖等待

点击“生成全部资产”只提交缺失且满足依赖条件的参考图，基础资产优先。角色/场景状态依赖的是创建时冻结的 parentVersionId；基础图生成但未人工锁定时仍不能生成状态图。

- 正常等待放入 waiting，不再当作错误。全部都在等待或已有结果时，按钮只给出说明，不提交任务、不显示失败。
- 塑角造景显示可展开依赖摘要；“查看基础资产 Vn”切换到对应版本并滚动至详情，支持父资产未直接绑定本集分镜的情况。
- 用户确认锁定基础图后再次批量生成，补齐状态图；不自动锁定、不提前提交状态任务、不自动后台续跑。
- 删除/弃用的卡片排除；队列任务、同步中结果、已生成参考跳过。父版本缺失、已弃用、归属错误或锁定但无参考图仍为真实错误。
- 单项失败不阻断其他独立资产；错误带资产名；连续点击有同步提交锁。切换项目后停止剩余批量提交。

验证：batch_generation、film_bible_references、film_bible_job_progress 前端测试及 test_visual_references 后端校验，未调用付费模型。
