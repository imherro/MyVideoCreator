# 可选构图预览

新导入、新增镜头保存 `compositionMode: direct`，默认直接生成视频。
在分镜规划、分镜图或视频设置中，可逐镜选择“先看构图再拍视频”（`preview`）。同集允许混用。

- 多模态直接生成：使用绑定且已确认的角色、场景、道具以及显式追加的素材，不自动提交该镜头的分镜图。
- 先看构图：须先生成有效构图图，再作为普通构图参考提交；不是严格首帧约束。
- 严格首帧/首尾帧仍须准备相应图片，不因制作方式而自动切换协议。
- 历史镜头缺少该字段时，保留已有构图图片的使用；不会清除图片、旧视频、任务快照或时间线。
- 显式改为直接生成不删除历史分镜图，但停止自动引用。手动追加的图片与角色绑定保持有效。
- 无可用参考素材、资产未绑定或主参考图未确认时，仍阻止提交，不降级为文生视频。

执行计划、逐镜/批量校验、工作流建议和过期传播使用同样的依赖规则。整画布执行默认不生成直接模式的可选分镜图；显式选中图像节点仍可生成。
任务快照保存实际 `composition_mode`，预览清单展示制作方式与真实媒体清单。修改制作方式只令相关视频需更新，不删除任何成片。

测试覆盖同集混用、严格帧模式、新旧镜头导入、过期构图不阻塞直接生成、保留角色参考、无参考阻止提交、明确生成可选图像以及制作方式切换保留原媒体。
