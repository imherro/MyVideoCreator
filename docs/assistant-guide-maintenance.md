# AI 助手指南维护

每次更改用户流程、按钮名称、位置、默认行为或生成前提时，一并核对：

- backend/assistant_guide.md：只描述已实现入口与限制，区分新任务与历史数据、界面更新与生成规则。
- backend/assistant.py：涉及当前状态的问题，按需补充只读、脱敏、限量的服务端上下文；避免把模型推测当成事实。
- tests/test_assistant.py：验证项目隔离、凭据脱敏、助手不写项目或提交制作任务，以及新增状态的含义。
- 指南中的模型名称和适配能力不代表账号已开通，能力以实际提交前校验为准。
- 未持久化的 UI 行为不能宣称已读取，例如点击应用/撤销。文字相同只表示一致，不证明发生过某个操作。
- 指南随代码提交；本机重启服务后加载新指南。远程部署由专门会话处理。

当前版本补齐创作约束、Video Prompt AI 优化、声音样本、剪辑下载、新视频模型及商用文本限制。
