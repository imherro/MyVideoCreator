# 角色音色选择与紧凑资产详情

- 官方来源：https://www.volcengine.com/docs/6561/1257544 （2026-09-17 核对实际页面的 TTS 2.0 / S2S-O2.0 音色表）。精选 39 个新版中文音色：28 通用、4 角色扮演、5 视频配音、2 有声阅读；Vivi、小何、云舟、小天置顶。保留 9 个旧 ID，独立历史分类，不迁移已锁定声音。
- 选择器支持名称、男女声、Speaker ID 搜索及分类；点击只改变编辑草稿，不发起合成。自定义 ID 保留官方目录链接作为补充。
- 新声音优先取当前角色本集对白及情绪；没有对白时取当前集 canonical script 的短节选；不捏造试听文本。已有保存文本不被自动替换，用户可点击填入或选择另一镜对白。
- 8–15 秒为样本制作建议，不是硬性 API 校验。短对白完整保留，实际时长来自音频 metadata。剧本节选按完整句优先、限制长度；播放与锁定继续使用实际音频，不改变生成视频的时长策略。
- 点击生成试听后禁用重复提交，完成后内嵌音频播放器尝试自动播放，浏览器拒绝时提示手动播放。重新打开已有样本不会自动播放，切换角色或离开页面会停止音频。隔离 UI 测试使用本地 10 秒静音 WAV 和模拟任务，没有付费合成。
- 外观设定、主参考图、声音、分镜绑定分区；宽区域外观和参考图并排，角色声音与分镜绑定在下一行左右并排且始终展开；窄侧栏单列。目标分镜全部列出，每行显示当前版本绑定状态和绑定/解除操作；外观约束和本集对白详情仍按需展开。
