# 整部作品回收与视觉风格

## 回收范围

项目库作品标题右侧删除按钮针对整部作品，分集行删除按钮仅针对当前集。两者使用页面内名称确认框。整部回收保留数据库和媒体文件，禁止存在排队或运行任务时回收。

`deleted_items(kind=production)` 标记作品，`production_trash_members` 记录本次跟随回收的制作集。恢复只恢复这批集，不复活此前单独删除的集。回收中的作品禁止访问其工作流、创建集或提交新生成任务；先恢复整部作品才能恢复其单独回收的子资源。最后一部作品回收后，空白工作室仍提供回收站入口。

## 视觉风格契约

`shared/visual_styles.json` 是前后端共用的风格名称与描述来源，部署时需与 backend 一起保留该目录。`backend/visual_style.py` 将完整预设描述、Film Bible style 和 continuity 编译为带边界的项目视觉风格段落，应用到新资产参考图、分镜图、分镜规划和视频任务。

任务创建在冻结提示词前编译风格，视频提交前预览使用相同函数。任务 input.visual_style 保存实际快照；重试使用原快照，已存在任务的提示词不重写。任务详情展示快照和完整提交提示词。历史媒体不会自动重新生成。

新图片指纹包含完整风格上下文，旧指纹比较兼容缺少该字段的历史记录。视频结果比较只对采用新风格契约的任务重建风格，避免仅升级代码就误判历史视频过期。

## 验证

`tests/test_production_trash_style.py` 覆盖整部回收/恢复、此前单集删除、空作品、活动任务保护、风格展开/去重、自定义风格、Bible 约束、新旧指纹、视频过期判断、单次/批量/预览及重试一致性。界面使用独立数据目录验证整部删除及空工作室恢复，不调用真实模型。
