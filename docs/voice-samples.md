# 角色音色样本参考

## 使用

1. 在塑角造景选择角色，展开「角色固定声音」，选择音色并生成试听。
2. 试听后点击「锁定为角色声音参考」。旧项目已锁定但未确认样本的角色，点击「将试听确认为角色声音参考」。建议每个角色使用 3–6 秒自然、清晰的样本。
3. 项目设置 → 当前制作集设置 → 默认对白方式，选择「音色样本参考」。视频生成模式须明确选择「多模态参考」。视频工作区和高级画布的镜头设置支持覆盖这两个选项。
4. 点「预览最终提交与参考清单（不生成）」检查每个说话角色对应的音频、台词、情绪和时长，再生成视频。无需先生成本集全部对白。

保留「完整对白参考」：先合成本镜对白，以完整音频的内容和时序引导视频；已有旧任务仍按其冻结输入处理。

## 语义与持久化

- `Project.document.dialogueMode` / `shot.dialogueMode`：`voice_sample` 或 `full_dialogue`。新项目默认前者；缺少字段的旧项目迁移为后者。镜头未指定时继承所在制作集设置。
- `filmBible.voices.profiles[cardId].referenceAssetId/referenceVersion` 独立保存已确认声音样本。`previewAssetId` 更新不替换已确认样本；创建新声音版本会清除确认，需重新试听锁定。
- 只收集本镜实际说话的角色，各角色独立音频，按首次对白出现顺序编号；同一文件去重传输，仍保留每个角色的映射。不把所有角色混为一条音轨。
- 编译提示词逐角色指定「仅参考音色，不复述样本内容，不沿用样本情绪、语调或时长」，对白和情绪来自本镜结构化台词。存在角色视觉绑定时，同时关联图片编号。
- 样本时长不参与镜头时长计算，不做时间线对白合成、不做下载后覆盖音轨。视频及声音由模型返回。样本参考不等于声音复刻质量保证，需人工听辨音色、情绪及多角色串音情况。
- 任务冻结 `dialogue_mode`、`voice_samples`（角色、资产、声音版本、实际时长、SHA256、序号），以及统一的 `reference_manifest`。不保存 API key 或临时媒体链接。
- 预览、单镜头、批量共用编译链路。更改声音确认或版本会更新相关视频及下游节点的生成版本、保留旧成果并标记待更新；跨集共享角色声音同样更新相关集。旧任务输入和远端恢复不变。

## 适配边界

音色样本只在明确的多模态模式提交。严格首帧/首尾帧下阻止提交并展示主动切换入口，切换后图片变为构图参考，不静默改变意图。

- 方舟 Seedance 2.0/2.5：按角色发送独立 `audio_url` + `reference_audio`，开启 `generate_audio`。
- RunningHub Seedance 2.5 token/global-token：独立上传每份样本，传 `audioUrls`，开启 `generateAudio`。
- 幻场及未核实的模型：当前适配器不支持此方式，明确报错；不会自动换模型、降级或丢弃样本。
- 提交前检查素材归属、删除状态、实际音频格式/时长、数量与总时长，并冻结文件哈希。当前样本要求 MP3/WAV、每份不超过 15 MB，2.0 最多 3 份且总计不超过 15 秒，2.5 最多 10 份且总计不超过 30 秒；每份至少 2 秒。首次执行时重新验证哈希，远端恢复不重新上传。

提示词设计参考：[官方音色一致性 FAQ](https://ai.byteplus.com/en/help/article/how-do-i-keep-a-consistent-voice-timbre-when-using-a-reference-audio-and-avoid-the-model-reading-the-reference-content-aloud)。模式协议见 [动作参考说明](motion-reference.md)。

## 验证（2026-09-16）

自动测试覆盖模式继承/旧项目兼容、固定样本不受试听更新影响、按说话角色绑定和去重、保留本镜情绪、样本不延长视频、非法/丢失素材与不兼容模式拦截、方舟与 RunningHub 请求体、远端恢复不重传、预览/单次/批量一致、局部及跨集过期、历史任务快照不变。

真实方舟 `doubao-seedance-2-5-260628` 测试：一张合成机器人图、一段豆包 TTS 音色样本（6.84 秒）、不同的新台词及开心情绪、无动作视频，设置 4 秒/480p。成功返回 854×480、24 fps、4.064 秒、包含音轨的 MP4。测试保存在隔离数据目录 `data/voice-sample-smoke`，未修改用户项目。此结果验证请求和成片链路，音色相似度、多角色及强烈情绪仍需人工试听验收。RunningHub 当前为 Mock HTTP 验证，未重复付费测试。
