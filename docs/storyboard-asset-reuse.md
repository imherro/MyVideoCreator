# 跨集分镜规划复用资产

分镜规划属于当前制作集，角色、场景、道具、状态和声音身份属于整部作品。生成或重新导入 EP02 不能替换共享视觉资产库，也不能删除 EP01 已引用的版本。

## 生成

提交单次或画布批次分镜任务时，服务端从当前 Production 冻结 `storyboard_visual_context`，包含作品编号、共享版本号、视觉卡及历史版本。浏览器不能用过时或伪造的清单替代服务端数据；同一 submission ID 的重试沿用原快照。

视觉提取阶段的实际 User Prompt 包含可用资产清单：稳定 key（卡片 ID）、名称/已确认别名、类型、父级、外观、不可变约束、版本和参考图确认信息。指示模型：

- 同一身份沿用已有 key；简称或称谓变化不新建人物。
- 换装、化形、持续伤势、昼夜等通过关联状态表达，保留基础身份。
- 只为确实新增的实体/状态创建 key，不向本集塞入无关的旧资产或剧情。

服务端优先解析明确的 key；模型仍输出新语义 key 时，仅在名称/已确认别名、类型和父级唯一匹配时复用。歧义进入原有一次修正流程，不做模糊猜测。复用保留既有版本及参考图，不接受模型改写已有外观。分镜导演阶段收到复用后的真实外观及约束，绑定和对白角色 ID 使用同一份映射，因此仍能找到角色固定声音。

已删除/弃用资产不作为自动复用候选，但历史记录保留。既有任务未带清单时保持原有输入及执行行为。

## 导入与并发

自动导入与手动「导入分镜表」共用 `mergeStoryboardResult`：

- 以浏览器最新共享资产库为底，合并新增卡片和版本，保留全部历史版本。
- 同 ID 的当前卡片/版本优先，迟到任务快照不能覆盖后来锁定的参考图、声音或其他 Bible 配置。
- 旧任务结果里重新编号的同名实体可保守复用；同时重映射角色/场景/道具绑定、状态父级版本以及对白角色 ID。
- 不靠名称子串自动合并；明确确认的简称可记录在 `VisualCard.aliases`，且仍受类型、父级和唯一候选约束。
- 原有保存 revision 检查、锁定版本只读、跨集引用完整性保护继续生效。

## 回归验证

测试覆盖 EP02 复用 EP01 角色和状态、参考图及声音身份保留、新状态的父级版本、已删除资产/类型错误/同名歧义拦截、两轮提示词的资产上下文、单次/批次/重试快照一致、旧结果导入、迟到结果保护、名称相同但父级不同的状态不混用。

本次问题项目的恢复使用已成功任务，不重新调用模型：按原剧本确认角色称谓、化形前后身份、场景及道具的对应关系，复用旧卡并仅添加新的场景综合状态和角色化形状态。原任务输入/结果不改写；恢复前备份数据库，保存后核对 EP01 文档逐字不变。恢复文件和审计留在本地 `data/storyboard-repair`，不提交用户资料到仓库。
