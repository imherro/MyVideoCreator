# 智能导入剧本（试用版）

剧本室提供「智能导入 TXT / MD」。原著页选择 TXT / Markdown 后也先进入同一个预览，可选择「仅作为原著导入」。普通小说继续走原著与改编链路；已有分集成稿可以直接进入剧本、分镜规划。

## 流程

1. 读取文件（UTF-8，无法解码时尝试 GB18030），先按「第1集」「第一集」「EP01」等标题识别分集。
2. 预览显示标题、原文明示时长、原文、共享设定、缺失集和疑似截断。分集标题优先于 Markdown 集内小标题。
3. 用户点击「AI 智能识别与检查」，使用项目默认文本模型创建 production 范围任务。System Prompt / User Prompt / Schema `script-import/v1` 都进入任务快照。
4. 模型只返回原文行范围和元数据。已有明确标题边界不可改变；行范围不能重叠、留空洞或丢弃末尾。没有明确标题时可建议已有内容的分集，不得续写。
5. 确认所选集后，事务内建立/填充空集的正式剧本。原文件完整内容保存在原著文档 metadata，分集内容保存为章节并关联对应剧本。原文正文不经过模型重写；正式剧本复用既有存储，裁去外层空白。
6. 明示每集时长写入剧本和该集 document.duration；未说明时沿用项目时长。缺少的集不会自动生成空集。
7. 第一集之前的共享说明可追加到 Film Bible.story.summary。项目设置可查看、修改；后续分镜任务会携带这些共享设定以保持人物一致性。不会在导入时生成图片或视觉卡。

## 状态与保护

- 分集已有剧本、画布内容、镜头、时间线、活动任务或在回收站时不能覆盖。提交前再次检查，任一冲突回滚整次导入。
- 同一导入确认具有幂等性。相同文件再次打开会复用未确认预览和活动 AI 任务，不重复收费；用户主动重新 AI 检查除外。
- 识别完成仅更新预览，不自动导入。关闭弹窗后任务继续；重新选择相同文件可取回结果。
- 模型失败保留标题识别结果；不自动重试付费调用。预览刷新失败会重试读取，不重提模型任务。
- 原稿不完整的集显示「内容待补全」；修改正文保存后清除该导入提醒。模型检查不会自动修正错名。
- 当前单文件上限 12 万字符 / 6000 行、最多 500 集。没有明确标题时，AI 建议边界仍需人工检查。
