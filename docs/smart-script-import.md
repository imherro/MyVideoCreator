# 智能导入剧本（试用版）

剧本室提供「智能导入文档」，原著页提供「导入文档」。支持 TXT、Markdown、DOCX（含 WPS 保存的 DOCX / 兼容 DOCX 容器的 WPS）、文字型 PDF、RTF、ODT。原著页默认将预览分集存入原著资料库，也可切换为直接建立分集剧本。普通小说继续走原著与改编链路；已有分集成稿可以直接进入剧本、分镜规划。

## 流程

1. 文件上传至后端本地提取文字，支持 UTF-8、UTF-16、GB18030 文本编码，先按「第1集」「第一集」「EP01」或明确章节标题识别。DOCX 表格中的文字也按文档顺序读取。
2. 预览显示标题、原文明示时长、原文、共享设定、缺失集和疑似截断。分集标题优先于 Markdown 集内小标题。
3. 上传后先显示「本次分析的文本模型」，预选项目默认值，允许更换。点击「确认模型并开始 AI 分析」才提交任务，不会自动调用默认模型。本次选择写入任务快照，不修改项目默认模型。无明确章节/分集标题时，AI 结合单集目标时长、对白容量、动作节奏与剧情转折判断是否拆分。已有明确标题可直接导入。System Prompt / User Prompt / Schema `script-import/v2` 与目标时长进入任务快照。
4. 模型只返回原文行范围和元数据。长段落按句子建立逻辑行索引，拼接后仍是原文，不增加或删除字符；无标题时必须从首行到末行全覆盖。已有明确标题边界不可改变；行范围不能重叠、留空洞或丢弃末尾。没有明确标题时可建议已有内容的分集，不得续写。
5. 选择「导入原著资料库」时，将选中分集存为原著章节；已有原著则追加，原有分集剧本、镜头、视频不变，也不自动新增制作 EP。需要直接建立制作集时可选「直接建立分集剧本」。此时确认所选集后，事务内建立/填充空集的正式剧本。原文件完整内容保存在原著文档 metadata，分集内容保存为章节并关联对应剧本。原文正文不经过模型重写；正式剧本复用既有存储，裁去外层空白。
6. 明示每集时长写入剧本和该集 document.duration；未说明时沿用项目时长。缺少的集不会自动生成空集。
7. 第一集之前的共享说明可追加到 Film Bible.story.summary。项目设置可查看、修改；后续分镜任务会携带这些共享设定以保持人物一致性。不会在导入时生成图片或视觉卡。

## 状态与保护

- 分集已有剧本、画布内容、镜头、时间线、活动任务或在回收站时不能覆盖。提交前再次检查，任一冲突回滚整次导入。
- 同一导入确认具有幂等性。相同文件再次打开会复用未确认预览和活动 AI 任务，不重复收费；用户主动重新 AI 检查除外。
- 识别完成仅更新预览，不自动导入。关闭弹窗后任务继续；重新选择相同文件可取回结果。
- 模型失败保留标题识别结果；不自动重试付费调用。预览刷新失败会重试读取，不重提模型任务。
- 原稿不完整的集显示「内容待补全」；修改正文保存后清除该导入提醒。模型检查不会自动修正错名。
- 当前单文件上限 20 MB、12 万字符 / 6000 逻辑行、最多 500 集；PDF 最多 500 页。扫描件、加密或损坏的 PDF 明确提示，不静默漏页。
- 旧 DOC 需要服务器上提供 LibreOffice（PATH 或 MVC_SOFFICE）；未提供时提示另存为 DOCX。旧版 WPS、扫描版 PDF 不在本次兼容范围，不做 OCR。新依赖由 `pip install -r requirements.txt` 安装。
- 「按原文结构导入」跳过 AI 分集结果，按原有标题保存；无标题时作为一章，不会强制丢弃导入内容。没有明确标题时，AI 建议边界仍需人工检查。

## 后台导入交互

- 分析任务提交后自动收成右下角状态条，工作区与任务中心仍可操作；主动展开才显示完整预览。
- 状态条有任务详情入口，完成后显示「查看结果」，不会强行重新弹出遮罩。
- 关闭状态条、切换页面或刷新后，在原著 / 剧本页通过「继续导入」恢复服务端预览；浏览器按作品和入口保存预览编号及原著追加目标。任务记录也可恢复未确认的最新分析结果。
- 恢复预览只读取已有结果，不上传文件、不重新提交 AI。当前版本保留最近一次导入入口，完整分析任务仍在任务中心中。
- 浏览器隔离验证：后台状态时工作区按钮可操作，关闭后能恢复，确认时自动分析总调用数仍为一次。
