# 画布构图辅助

入口统一为「高级画布 → 添加节点 → 构图辅助」：

- 全景场景：选择已有 2:1 等距柱状全景图，或创建独立全景图生成节点，生成后再取景。
- 3D 构图：摆放角色占位物、场景物体，设置摄影机并保存构图。

分镜表不再提供独立「3D 导演台」页签。资产中心保留已有图片的「全景取景」，不再承担创建全景节点的入口。

## 使用和数据约定

每个辅助节点使用 reference 类型，通过 compositionType 区分 panorama/director，并将参数保存在自身 data.composition。第一次添加 3D 构图时兼容载入旧 document.director；多个节点之间不共享可变布景。

保存截图后自动建立「构图参考图」输出节点并连接辅助节点。输出节点可以连接到图像/分镜图节点。再次保存复用输出节点，保留下游连线；修改构图会标记输出和下游结果待更新。截图同时作为项目图片素材保存。

辅助节点上的预览使用 previewAssetId，真正提交的静态参考节点使用 assetId。全景原图与取景截图分离，防止将 360° 原图直接当成普通构图图。

取景和 3D 截图默认跟随项目图像画幅，也可以显式覆盖。截图长边 1280 像素；全景原图使用 2:1（推荐 3072×1536）。目前 RunningHub 图像适配器未开放 2:1，因此会明确拒绝全景原图生成；可改用支持像素尺寸的服务或上传现成全景图。

## 生成链路

图像参考编译器把构图图追加在角色、场景、道具参考之后，提示词明确说明各图用于站位、空间布局和摄影机角度。Film Bible 的身份和服装参考继续保留；总图数超出模型上限时拒绝提交，不静默丢弃参考。

构图输出和来源的内部连线只表示关系，不作为自动执行依赖。执行分镜图不会因此自动重新生成全景原图或创建付费任务。构图图 ID 和构图描述参与分镜图生成指纹；过期构图需要先重新保存。

3D 工具用于静态白模构图，不提供角色动画或自动动作视频。
